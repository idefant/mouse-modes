# Mouse Modes

Удерживайте сочетание клавиш, чтобы замедлить или ускорить курсор, прокручивать страницу движением мыши по горизонтали, вертикали или сразу по двум осям. Отпустите клавиши — вернётся обычное движение.

## Настройка

Нажмите кнопку с клавиатурой напротив нужного режима, зажмите сочетание и отпустите все клавиши. Во время записи сочетание не передаётся другим приложениям.

Левые и правые Ctrl, Shift, Alt и Win различаются. Чтобы подошла любая сторона, при записи зажмите оба модификатора. Например, левый Ctrl + правый Ctrl + F13 назначит **Ctrl с любой стороны + F13**.

Настройки применяются сразу. Изначально все сочетания пустые; кнопка сброса очищает назначение. Ускорение имеет приоритет над замедлением, направления прокрутки можно объединять.

Закрытие окна, в том числе по Ctrl+W, оставляет программу в трее. Во время записи сочетания Ctrl+W доступно для назначения. Нажмите значок, чтобы открыть меню «Настройки / Выход». Переключатель автозапуска включает запуск при входе в систему со скрытым окном.

## Установка

Скачайте установщик из [последнего стабильного релиза](https://github.com/idefant/mouse-modes/releases/latest): `.exe` для Windows, `.deb` для Debian/Ubuntu или `.rpm` для Fedora и других RPM-дистрибутивов или `.pkg.tar.zst` для Arch Linux/Omarchy. Предварительные версии доступны в [списке релизов](https://github.com/idefant/mouse-modes/releases). Для каждого выпуска публикуется файл `SHA256SUMS`. История изменений — в [CHANGELOG.md](CHANGELOG.md).

## Запуск

Запустите `mouse-modes` на Linux или `mouse-modes.exe` на Windows. Сборка из исходников описана в [CONTRIBUTING.md](CONTRIBUTING.md).

**Linux:** поддерживаются Wayland и X11. Пакеты `.deb`, `.rpm` и `.pkg.tar.zst` автоматически настраивают службу ввода systemd: при запуске и автозапуске не нужен отдельный пароль или ручная настройка прав. Служба работает под отдельной непривилегированной учётной записью, окно программы — под вашей. Поддерживается активный локальный графический сеанс; при смене пользователя обработка приостанавливается и затем восстанавливается. Зависимости устанавливает пакетный менеджер. Для переносной сборки и запуска из исходников используется отдельная авторизация polkit. Завершение программы освобождает устройства. Планшеты и абсолютные тачпады не преобразуются.

**Windows:** нужен WebView2. Системные защищённые сочетания, например Ctrl+Alt+Delete, недоступны для записи. Для работы с приложением, запущенным от администратора, может понадобиться такой же уровень прав у Mouse Modes.
