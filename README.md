# Mouse Modes

Одно окно настроек, пять режимов мыши по удержанию сочетания и системный трей. Tauri 2, Rust, React, TypeScript, Zod и SCSS Modules. Все сочетания изначально пустые, автозапуск выключен. Настройки сохраняются сразу в `settings.json` в системном каталоге конфигурации приложения.

## Использование

Нажмите кнопку с клавиатурой напротив режима, зажмите сочетание и отпустите все клавиши. Пока идёт запись, клавиши подавляются до приложений и не включают режимы. Левая и правая стороны модификаторов различаются; зажмите обе стороны одного модификатора, чтобы назначить любую сторону. Сброс очищает назначение. Одинаковые сочетания могут включать несколько режимов: ускорение имеет приоритет над замедлением, оси прокрутки объединяются.

Обычное закрытие окна прячет его. Клик по значку трея открывает меню «Настройки / Выход». Автозапуск открывает программу скрытой в трее. В некоторых Linux панелях левый клик обрабатывается самой панелью: меню Tauri предоставлено через StatusNotifier/AppIndicator.

## Разработка и сборка

Нужны Node.js 22.12+ и Rust stable. Linux: GTK3, WebKitGTK 4.1, AppIndicator, Python 3, python-evdev, polkit. На Arch/Omarchy: `webkit2gtk-4.1 libappindicator-gtk3 python-evdev polkit`. Windows: Visual Studio C++ Build Tools и WebView2.

```sh
npm ci
npm run tauri dev
npm run check
npm test
python3 linux/test_helper.py # Linux
cargo test --manifest-path src-tauri/Cargo.toml
npm run tauri build -- --no-bundle
# Установщик для текущей ОС:
npm run tauri build -- --bundles appimage # Linux
npm run tauri build -- --bundles nsis     # Windows
```

## Платформы

**Linux / Wayland / X11.** Ввод обрабатывает отдельный минимальный Python-процесс через evdev/uinput. GUI остаётся обычным пользователем. Polkit запрашивает разрешение при запуске для доступа к физическим устройствам; не нужны изменение групп, постоянные разрешения на `/dev/input` или правила polkit. Процесс получает настройки через pipe и освобождает устройства при его закрытии. Нужен загруженный `uinput`. Захват ввода завершается автоматически по тайм-ауту. Горячее подключение устройств поддерживается. Замедление ×0,25, ускорение ×2; прокрутка по 20 сырых единиц на щелчок. Конкурирующие программы с эксклюзивным захватом тех же устройств нужно остановить.

**Windows.** Нативный low-level keyboard hook подавляет запись и назначенные сочетания. Физические scan-коды сохраняют привязки при смене раскладки. Мышь через Raw Input; скорость меняется на ±10 пунктов системного диапазона 1–20, как в исходном `mouse.ahk`. Прокрутка фиксирует курсор и использует сырые смещения; исходная скорость и ограничение курсора восстанавливаются при отпускании и завершении. Защищённый экран Windows и системные сочетания вроде Ctrl+Alt+Delete не перехватываются обычными программами. Для управления приложениями, запущенными от администратора, может требоваться такой же уровень прав.

## Проверки

`npm run check` запускает TypeScript, ESLint и Stylelint; `npm test` проверяет Zod-схему. Rust проверяет общую модель и Windows matching/capture; Python тестирует Linux преобразование движения, модификаторы, подавление, завершение записи и обновление настроек. CI собирает Linux и Windows отдельно. Проверки на Linux не заменяют живое тестирование Windows.

Справка API: [Tauri tray](https://v2.tauri.app/learn/system-tray/), [Tauri autostart](https://v2.tauri.app/plugin/autostart/).
