# Mouse Modes

Удерживайте сочетание клавиш, чтобы замедлить или ускорить курсор, прокручивать страницу движением мыши по горизонтали, вертикали или сразу по двум осям. Отпустите клавиши — вернётся обычное движение.

## Настройка

Нажмите кнопку с клавиатурой напротив нужного режима, зажмите сочетание и отпустите все клавиши. Во время записи сочетание не передаётся другим приложениям.

Левые и правые Ctrl, Shift, Alt и Win различаются. Чтобы подошла любая сторона, при записи зажмите оба модификатора. Например, левый Ctrl + правый Ctrl + F13 назначит **Ctrl с любой стороны + F13**.

Настройки применяются сразу. Изначально все сочетания пустые; кнопка сброса очищает назначение. Ускорение имеет приоритет над замедлением, направления прокрутки можно объединять.

Закрытие окна оставляет программу в трее. Нажмите значок, чтобы открыть меню «Настройки / Выход». Переключатель автозапуска включает запуск при входе в систему со скрытым окном.

## Запуск

Запустите `mouse-modes` на Linux или `mouse-modes.exe` на Windows. Сборка из исходников описана в [CONTRIBUTING.md](CONTRIBUTING.md).

**Linux:** поддерживаются Wayland и X11. При запуске системное окно запросит разрешение на доступ к устройствам ввода. Окно программы остаётся обычным пользовательским процессом. Нужны polkit, `uinput`, WebKitGTK 4.1 и AppIndicator; если разрешение отклонено, перезапустите программу. Завершение программы освобождает устройства. Планшеты и абсолютные тачпады не преобразуются.

**Windows:** нужен WebView2. Системные защищённые сочетания, например Ctrl+Alt+Delete, недоступны для записи. Для работы с приложением, запущенным от администратора, может понадобиться такой же уровень прав у Mouse Modes.
