# Changelog

История изменений Mouse Modes. Для каждого git-тега обязательна отдельная запись с датой; её содержимое используется в описании GitHub Release.

## [Unreleased]

## [0.1.3] - 2026-10-27

### Добавлено

- Название приложения и номер версии внизу окна настроек.
- Закрытие окна настроек по Ctrl+W с сохранением работы в трее.

### Исправлено

- Одиночное нажатие ЛКМ по значку трея открывает приложение; ПКМ сохраняет контекстное меню. В Linux используется StatusNotifierItem с отдельной обработкой активации.
- Окно настроек больше не открывается самопроизвольно при блокировке и выходе Linux из сна: изменения состояния ввода после успешного запуска сохраняют видимость окна. Ошибки первоначального запуска по-прежнему показывают настройки.

## [0.1.2] - 2026-10-22

### Исправлено

- В Windows восстановлена запись горячих клавиш при активном окне настроек, включая F13–F24 от программируемых кнопок и переназначения клавиатуры.
- Устранён сбой обработчика Windows при повторном входе во время системных вызовов; ограничение курсора корректно снимается после отпускания горячих клавиш прокрутки.
- Запись сочетания отменяется при потере фокуса окна; переключение рабочего стола, блокировка и отключение устройства сбрасывают состояние ввода.

## [0.1.1] - 2026-10-21

### Добавлено

- Нативный установщик Arch Linux/Omarchy `.pkg.tar.zst` для стабильных выпусков.

### Исправлено

- Пакеты `.deb`, `.rpm` и `.pkg.tar.zst` автоматически настраивают службу ввода без root: отдельный пароль при запуске и ручная настройка прав больше не нужны.
- Служба проверяет активный локальный сеанс, освобождает устройства при блокировке и смене пользователя; соединение восстанавливается автоматически.
- Автозапуск переносной сборки Linux повторяет получение доступа к вводу в течение 30 секунд, если агент polkit ещё не готов. Отмена пользователем не вызывает повторный запрос.
- Ошибка службы ввода открывает окно настроек; сообщения pkexec сохраняются в журнале сеанса.

## [0.1.0] - 2026-10-20

### Добавлено

- Первый стабильный выпуск Mouse Modes после успешной сборки и публикации `0.1.0-alpha-1`.
- Замедление и ускорение курсора, горизонтальная, вертикальная и двухосевая прокрутка при удержании назначенных сочетаний клавиш.
- Запись сочетаний с различением левых и правых модификаторов, сохранение настроек, меню в трее и автозапуск.
- Поддержка Windows и Linux (Wayland и X11); нативный обработчик ввода Linux получает доступ к устройствам через polkit.
- Установщики Windows NSIS (`.exe`), Debian/Ubuntu (`.deb`) и RPM (`.rpm`), а также контрольные суммы SHA-256.
- CI/CD с проверками обеих ОС, версией из git-тега и описанием релиза из соответствующей записи CHANGELOG.

### Исправлено

- Совместимость CI с Windows: кавычки в команде Stylelint и окончания строк CRLF при синхронизации версий.
- Упаковка предварительных версий с учётом ограничений RPM в Tauri.
- Имена файлов в `SHA256SUMS` совпадают с именами скачиваемых файлов GitHub Release.

## [0.1.0-alpha-1] - 2026-10-20

### Добавлено

- Первый предварительный выпуск Mouse Modes для Linux (Wayland и X11) и Windows.
- Замедление и ускорение курсора, горизонтальная, вертикальная и двухосевая прокрутка движением мыши при удержании назначенных сочетаний клавиш.
- Запись сочетаний с различением левых и правых модификаторов, сохранение настроек, меню в трее и автозапуск.
- Нативный обработчик ввода Linux с доступом через polkit и поддержкой составных HID-устройств.
- Автоматические проверки и сборка установщиков Windows NSIS (.exe), Linux Debian (.deb); для стабильных версий также RPM (.rpm).
- Выпуск по git-тегу: версия синхронизируется в манифестах, описание релиза берётся из соответствующей записи CHANGELOG.

### Исправлено

- Совместимость команд проверки стилей и синхронизации версий с Windows, включая окончания строк CRLF.
- Предварительные версии собираются в `.deb` и `.exe`; RPM создаётся для стабильных версий из-за ограничений упаковщика Tauri на суффиксы версии.
